---
title: Idea — Builder — Navigation — Save changes prompt when navigating away
priority: normal
status: pending
area: builder
---

When the user clicks "Back" or navigates away from a slide being edited, unsaved changes can be silently lost. Consider adding a "Save Changes" button or an unsaved-changes prompt that triggers before leaving the slide editor, ensuring all edits (including component settings like timing) are always persisted before navigation.
