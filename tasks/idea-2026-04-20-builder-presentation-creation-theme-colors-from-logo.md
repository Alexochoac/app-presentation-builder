title: Idea — Builder — Presentation Creation — Auto-generate theme colors from logo
priority: normal
status: pending
area: builder
---

When a customer uploads their logo during the presentation creation flow, automatically extract the dominant colors and apply them as CSS theme variables (primary, accent, background). Use a library like Color Thief (canvas-based, no backend required) to pull 2–3 dominant colors, then let the user preview and optionally tweak before saving to the customer config.
