---
title: Builder — Save Screen — New vs Replace — Remove redundant toggle, show as context signal instead
type: Issue
priority: M
status: pending
area: builder
---

The Save screen shows a "New presentation / Replace" toggle but this choice is already made at the entry point — either from the builder preview menu or the Your Presentations card menu. Having the toggle again on the Save screen is redundant and adds confusion. Remove it as an actionable control and replace it with a passive read-only label that confirms what action the user is about to take (e.g. "Creating new presentation" or "Replacing: [presentation name]"), so the screen reinforces context without offering a choice that was already made.
