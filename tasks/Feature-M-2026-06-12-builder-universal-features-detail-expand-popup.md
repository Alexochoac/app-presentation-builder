type: Feature

Any list item or text element on any slide can optionally display a small ↗ trigger icon that opens a popup — either a rich-text detail panel or an image gallery. The trigger is toggled and configured per-slide via the builder's Features panel, follows the universal-features model (server-injected, per-slide-toggled, per the Feature-Dock concept in standardization-plan.md), and the affordance ships to published decks.

This feature replaces the bespoke per-slide popups that are being dropped during lean rebuilds and must not be permanently lost:
- **Dimensions slide — item 6**: tolerances detail popup
- **Dimensions slide — item 9**: belt-conveyors image gallery popup
- **Why-Us slide**: "view chart" popup
