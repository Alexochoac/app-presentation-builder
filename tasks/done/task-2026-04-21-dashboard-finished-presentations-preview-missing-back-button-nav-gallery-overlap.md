When previewing a finished presentation from the dashboard, the header is missing both a back button and the navigation bar. Additionally, the gallery button on the hero/cover slide is visually overlapped by the footer. All three issues need to be fixed in the preview view.

## Implementation Summary

All three issues were in the frozen HTML generated by `buildFrozenPresentation` in `builder/server.js`.

**Root cause of gallery overlap:** The embedded `style.css` sets `.slides-container { height: 100dvh }`. The `.slides-container` sits inside `#fp-viewer` (which is `100vh - 44px - 32px`), but its full-viewport height caused the gallery button's `bottom: 80px` to be measured from the viewport bottom rather than the viewer bottom — placing it within the footer's visual area.

**Fixes in `buildFrozenPresentation` CSS:**

1. **Gallery button overlap:** Added `#fp-viewer .slides-container { height: 100% !important; width: 100% !important; }` to constrain the slides container to the viewer's actual height. Also added `.fp-slide .slide { height: 100% !important; }` for extra safety.

2. **Back to Dashboard button:** Added `<a href="/" id="fp-dash-btn">← Dashboard</a>` as the first element in `#fp-header`, with a vertical divider separator.

3. **Navigation bar in header:** Moved the prev/next navigation buttons (`#fp-prev`, `#fp-next`) from overlay position on the slide area into `#fp-header`, flanking the slide counter (`#fp-counter`). Replaced the large circular overlay style with compact inline header buttons (`.fp-nav-btn`). The overlay buttons were removed entirely.

**Header layout (left to right):** `← Dashboard` | divider | presentation title | `‹` | `1 / N` | `›` | (optional) `More ▾` / `← Back to Presentation`
