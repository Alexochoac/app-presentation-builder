type: Feature

Add a collapsible submenu under the Builder nav item in the sidebar, mirroring the pattern already in place for Slides (My Library / Templates / Slide Builder). The Builder nav item becomes a section header that expands to show a live list of decks loaded from the API, plus fixed sub-items for Preview and Publish. Deck names in the sidebar link to the builder scoped to that deck. The list collapses when the sidebar is collapsed.
