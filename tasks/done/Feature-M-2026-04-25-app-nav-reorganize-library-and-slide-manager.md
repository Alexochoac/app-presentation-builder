Reorganize the main navigation and Builder section layout to reflect the two distinct workflows:

1. **Library moves within Builder** — the Library section (currently a tab inside Slide Manager on the Builder page) should move to sit below the "Your Presentations" card on the Builder section, not inside Slide Manager.

2. **Slide Manager becomes a top-level sidebar item** — currently a tab inside the Builder page, Slide Manager should become its own entry in the main sidebar (below Builder). It is a separate workflow: create and work on new slides, then optionally save them to the library, then add them to a deck. It is not part of the build/publish flow.

**Intended flow:**
- **Builder** = assemble a deck from library slides → build → publish finished presentations
- **Slide Manager** = create and edit raw slides → save to library when ready
