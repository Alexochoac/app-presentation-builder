Add a view toggle to the Finished Presentations section so the user can switch between:

- **List view** (default) — current compact rows with name, meta, and action buttons
- **Grid view** — cards with a mini thumbnail area (slide count badge, customer initials placeholder) for quick visual scanning

The toggle (list icon / grid icon) lives in the panel header, right side. Selection persists in localStorage.

Future: the Grid card can later host a real slide thumbnail once a screenshot/preview API exists.
