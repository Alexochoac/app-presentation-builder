---
title: Builder — Image Upload — Gallery — Show uploaded assets for reuse
type: Feature
priority: M
status: pending
area: builder
---

When the user triggers an image upload in the builder, show a gallery of already-uploaded images so they can select an existing asset instead of re-uploading it. The current flow opens a bare file picker every time with no way to reuse previously uploaded images. The gallery should let the user pick from existing uploads or upload a new file.
